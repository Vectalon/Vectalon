# @vectalon/rn

**The adaptive AI harness for React Native.**

## Installation

```bash
npm install --save-dev @vectalon/rn
# or
yarn add -D @vectalon/rn
# or
pnpm add -D @vectalon/rn
```

## Quick Start

```bash
npx vectalon init    # Scan project, build context
npx vectalon serve   # Start MCP server for agents
```

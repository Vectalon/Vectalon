# Admin Dashboard

**Internal tool for Vectalon operations.**

## Features

- License generation and revocation
- Trial analytics
- Revenue dashboard (MRR, ARR)
- Customer management
- API health monitoring

## Tech Stack

- Next.js + Tailwind + shadcn/ui
- SQLite / Supabase
- GitHub OAuth (admin-only)

## Setup

```bash
cd packages/admin
pnpm install
pnpm dev
```

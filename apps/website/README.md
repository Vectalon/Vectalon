# vectalon.in

**The Vectalon website and documentation.**

## Tech Stack

- Next.js + Tailwind CSS
- Vercel hosting
- Mintlify for documentation

## Development

```bash
cd apps/website
pnpm install
pnpm dev
```

## Pages

- `/` — Landing page
- `/pricing` — Pricing tiers
- `/trial` — Start trial (GitHub OAuth)
- `/docs` — Documentation
- `/changelog` — Release notes
- `/blog` — Technical content
